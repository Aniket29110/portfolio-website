# Animated Portfolio Website

This is a modern personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- Animated hero, skills, and project sections
- Responsive navigation for desktop and mobile
- Smooth scrolling between sections
- Frontend-only contact form

## Getting Started

1. Open the project in your code editor.
2. Navigate to the `frontend` directory.
3. Install dependencies with `npm install`.
4. Start the app with `npm run dev`.

## Contact Form

The contact form does not require a backend.

When a visitor submits the form, the site opens their default email app with your email address, subject, and message prefilled.

## Deployment

The frontend can be deployed on platforms like Vercel or Netlify.
